# Ticket Management APIs

--------------------------------------------

## Get All Tickets

* **GET** /api/tickets

* Returns all tickets with related information:

  * User
  * Assigned Support Agent
  * Category
  * Priority
  * Status

Features:

* Search
* Filtering
* Sorting
* Pagination

--------------------------------------------

## Get Single Ticket

* **GET** /api/tickets/{ticket}

* Returns details of a specific ticket.

--------------------------------------------

## Create Ticket

* **POST** /api/tickets

* Creates a new ticket.

Features:

* Generates unique ticket number
* Assigns logged-in user as ticket owner
* Sets default status to Open

--------------------------------------------

## Update Ticket

* **PUT** /api/tickets/{ticket}

* Updates ticket information:

  * Subject
  * Description
  * Category
  * Priority

--------------------------------------------

## Delete Ticket

* **DELETE** /api/tickets/{ticket}

* Deletes an existing ticket.

--------------------------------------------

## Assign Ticket

* **PATCH** /api/tickets/{ticket}/assign

* Allows Admin users to assign tickets
to Support Agents.

* Changes ticket status to Assigned.

--------------------------------------------

## Start Ticket

* **PATCH** /api/tickets/{ticket}/start

* Allows assigned Support Agents to start
working on tickets.

* Changes ticket status to InProgress.

--------------------------------------------

## Resolve Ticket

* **PATCH** /api/tickets/{ticket}/resolve

* Allows assigned Support Agents to resolve
tickets.

* Saves resolution date and time.

--------------------------------------------

## Close Ticket

* **PATCH** /api/tickets/{ticket}/close

* Allows Admin users to close tickets.

* Saves closing date and time.

--------------------------------------------
